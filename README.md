# Jonathan Gunawan — Portfolio

Personal portfolio website showcasing backend-focused projects, technical experience, and contact information.

## Tech Stack

- HTML
- JavaScript
- Tailwind CSS 4

## Development

Install the dependencies:

```bash
npm install
```

Watch and rebuild Tailwind CSS while editing:

```bash
npm run dev
```

Open `index.html` through a local static server or Live Server.

## Production Build

Generate the minified stylesheet:

```bash
npm run build
```

Custom styles should be edited in `src/input.css`. The `css/style.css` file is generated by Tailwind and should not be edited manually.
